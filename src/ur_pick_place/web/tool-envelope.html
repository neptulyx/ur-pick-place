Tool box editor

This page works offline. The flange is the robot mounting face. tool0 is its reference frame.

DRAFT · FOR VIEWING ONLY

The example values are not measured. The orientation and coverage are uncertain. This page shows the tool box. It does not check for collisions. It does not change robot settings.

The box axes move with the tool box. The flange axes stay fixed to the flange.

Full dimensions of the tool box (mm)
Centre relative to the flange (mm)
Orientation (degrees)

Roll, pitch and yaw are rotations about X, Y and Z. The order is Rz(yaw) × Ry(pitch) × Rx(roll). A UR rotation vector describes orientation in a different way.

Each dimension must be more than 0 and no more than 5000 mm. Centre values must be between −5000 and 5000 mm. Angles must be between −360° and 360°. The margin must be between 0 and 1000 mm. The margin expands each face of the tool box.


JSON is a text format for data.
